This script disables pressate-biostimulant concentration while screening pretreatment cases.
The methane-yield values in pretreatment_summary_from_yaml.csv come from assumptions.yaml.
The economics outputs are from sabre/tea.py using make_baseline_tea(...) and solve_biomethane_msp(...).
Finance basis used here: IRR=10.00%, plant life=20 y, operating days=330.0 d/y.
Quality case simulated here: pelagic_high_quality
